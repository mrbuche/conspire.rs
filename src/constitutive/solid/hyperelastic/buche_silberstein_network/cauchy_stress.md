```math
\boldsymbol{\sigma}(\mathbf{F}) = \frac{C}{J}\left[\int_{S^2} G\!\left(w_0\,\mathbf{u}\cdot\bar{\mathbf{B}}^{-1}\cdot\mathbf{u}\right)\,(\mathbf{u}\otimes\mathbf{u})\;d\Omega\right]' + \frac{\kappa}{2}\left(J - \frac{1}{J}\right)\mathbf{1}
```
with the radial kernel
```math
G(w) = \int_0^\infty \eta(\lambda)\,\lambda^3\,e^{-w\lambda^2}\,d\lambda, \qquad w_0 = \frac{k_1 N_b}{2}, \quad k_1 = \frac{1}{\tfrac{1}{3} + \varkappa^{-1}},
```
$`\eta(\lambda)`$ the inverse of $`\lambda = \mathcal{L}(\eta) + \eta/\varkappa`$, and $`C = \mu\,N_b^{5/2}(k_1/2\pi)^{3/2} / \mu_\mathrm{raw}`$ chosen so $`\mu`$ is the small-stretch shear modulus.
